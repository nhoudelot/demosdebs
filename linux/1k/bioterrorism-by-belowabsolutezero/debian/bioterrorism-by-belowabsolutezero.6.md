# NAME
bioterrorism-by-belowabsolutezero - Bioterrorism, a 1k intro by Below Absolute Zero

# SYNOPSIS
bioterrorism-by-belowabsolutezero

# DESCRIPTION
Bioterrorism is a 1k intro released by Below Absolute Zero in August 2013.
It ranked 7th in the PC 1k competition at Assembly 2013.

The executable is a small shell header followed by the gzip-compressed
intro. It is unpacked in a private temporary file, run, then removed.

This package builds the "clean" version provided by the authors: the
intro runs in an 800x600 window and stops at the end of the music, or
when a key is pressed.

This program has no options.
