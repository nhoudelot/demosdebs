# NAME
inconsistency-by-hymy - the command to run Inconsistency.

# SYNOPSIS
inconsistency-by-hymy [*options*]

# DESCRIPTION
Inconsistency is a 1k intro released by Hymy in August 2013 at
Assembly 2013 (11th in the PC 1k compo).

The program is a shell script that contains the gzipped 32-bit ELF
executable of the intro: at each start, it is extracted into a temporary
directory, which is removed when the intro ends. The intro uses SDL 1.2
and renders the picture in software, in a 1280x720 window.

The intro lasts about one minute. Press Escape or close the window to quit.

# OPTIONS
There are no options.
