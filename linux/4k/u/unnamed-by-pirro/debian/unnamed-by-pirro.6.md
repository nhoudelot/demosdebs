# NAME
unnamed-by-pirro - run Unnamed, a 4k intro by piRro & fx

# SYNOPSIS
unnamed-by-pirro

# DESCRIPTION
Unnamed is a 4k intro by piRro and fx, released in 2004 for the 4k source
compo of 320x200.org. The whole intro, graphics and music included, fits in
4096 bytes of C source code using SDL 1.2.

It opens a 400x300 window and quits by itself at the end of the intro.

# OPTIONS
This program has no options.

# KEYS
Any key
:   quit the intro (closing the window quits too).

# INFOS
https://320x200.org/2004/4k/

# BUGS
No known bugs.
