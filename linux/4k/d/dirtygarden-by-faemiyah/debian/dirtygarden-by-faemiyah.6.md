# NAME
dirtygarden-by-faemiyah - the command to run Dirty Garden.

# SYNOPSIS
dirtygarden-by-faemiyah [*options*]

# DESCRIPTION
Dirty Garden is a 4k intro released by Faemiyah in August 2011.
It ended 8th at the Assembly 2011 4k intro compo.

Trilkk [Code]  
Warma [Additional code]  
Juippi [Music]

The intro starts in a resizable window.

# OPTIONS
\-f, \-\-fullscreen
:    Start in fullscreen mode.

\-w, \-\-windowed
:    Start in a window (default).

\-n, \-\-no-fullscreen
:    Same as \-\-windowed.

\-r, \-\-record
:    Do not run in real time: write every frame to dirty_garden_NNNN.png
     and the soundtrack to dirty_garden_audio.raw in the current directory.

Any other argument prints the list of valid options.

# KEYS
F
:    Toggle fullscreen.

Any other key
:    Quit.
