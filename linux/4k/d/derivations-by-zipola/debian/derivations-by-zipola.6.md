# NAME
derivations-by-zipola - 4k intro by zipola

# SYNOPSIS
derivations-by-zipola

# DESCRIPTION
Derivations is a 4k intro written in C with SDL and OpenGL by zipola
(Tuomo Sipola), released in November 2010 at Instanssi I/2010, where it
ranked 7th in the combined demo compo.

The intro runs in a 1024x768 window and lasts 45 seconds. Its sound is
generated when it starts, so the window can stay black for a moment.

# OPTIONS
This program has no options.

# KEYS
**Any key**
:   Quits the intro. Closing the window also quits it.
