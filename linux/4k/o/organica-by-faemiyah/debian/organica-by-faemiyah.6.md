# NAME
organica-by-faemiyah - the command to run Organica.

# SYNOPSIS
organica-by-faemiyah [*options*]

# DESCRIPTION
Organica is a 4k intro released by Faemiyah in August 2007.
Ranked 9th at Assembly 2007.

Warma [Additional code]
Trilkk [Code]
Juippi [Music]

# OPTIONS
-f, --fullscreen : Fullscreen mode (default).

-w, --windowed : Windowed mode (resizable window).

-r, --record : Do not run in real time, save the audio as a .wav file and the frames as .png files.

Any other argument prints the list of valid options.

# KEYS
f : Toggle fullscreen.

Esc, q : Quit.
