# NAME
sevenance-by-joga - the command to run Sevenance.

# SYNOPSIS
sevenance-by-joga [*options*]

# DESCRIPTION
Sevenance is an 8k intro (4864 bytes in its compressed party version)
released by joga in May 2016 at Simulaatio 2016, where it ended 4th in the
PC intro competition.

It runs fullscreen at the desktop resolution (despite the 1920x1080 in the
executable name) and requires OpenGL 3.3. Mind the volume: the soundtrack
is loud.

joga [Code]

# OPTIONS
\--help
:   Display help for the command

# NOTES
The executable shipped in this package is the unpacked version of the
party release.
