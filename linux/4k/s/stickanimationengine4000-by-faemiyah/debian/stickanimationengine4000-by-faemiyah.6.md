# NAME
**stickanimationengine4000-by-faemiyah** - the command to run Stick Animation Engine 4000.

# SYNOPSIS
**stickanimationengine4000-by-faemiyah**

# DESCRIPTION
**Stick Animation Engine 4000** is a 4k intro released by Faemiyah in august 2008.
Ended 2nd in the 4k intro competition at Assembly 2008.

Trilkk [Code]

Juippi [Music, synth]

The intro opens a resizable 1280x720 window, synthesises its soundtrack
at startup and quits by itself after 91 seconds.

# OPTIONS
This program has no options.

# KEYS
**F**
:    Toggle fullscreen.

**Esc**, **Q**
:    Quit.
