# NAME
shadowsun-by-tonic - the command to run Shadow Sun.

# SYNOPSIS
shadowsun-by-tonic

# DESCRIPTION
Shadow Sun is a 4k intro released by tonic in May 2004. It won the 2nd
#demoscene 4k source compo with 72 points.

It runs in a 640x480 OpenGL window, with music synthesized in real time.

# OPTIONS
This program has no options.

# KEYS
Escape
:   Quit the intro.

# INFOS
https://320x200.org/2004/4k/results.html
