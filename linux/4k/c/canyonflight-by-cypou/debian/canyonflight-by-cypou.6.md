# NAME
canyonflight-by-cypou - run Canyon Flight, a 4k intro released by cypou

# SYNOPSIS
canyonflight-by-cypou

# DESCRIPTION
Canyon Flight is a 4k intro written by Nathael PAJANI and Cyprien LAPLACE
(cypou) for the 2004 Linux 4k compo. A small plane flies through an
endless canyon generated randomly at each start, and changes lanes to
avoid the walls that block its way.

The intro opens a 640x480 OpenGL window and runs until it is stopped.

# OPTIONS
This program has no options.

# KEYS
**Escape**
:   quit the intro (closing the window also quits).
