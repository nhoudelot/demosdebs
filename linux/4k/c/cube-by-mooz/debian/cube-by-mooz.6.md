# NAME
cube-by-mooz - run Cube, a 4k intro released by MooZ

# SYNOPSIS
cube-by-mooz

# DESCRIPTION
Cube is a 4k intro written by MooZ for the 2004 Linux 4k compo. A grid
of small cubes is lit by three metaballs that drift through it: each
cube grows with the field around it. In rhythm, the picture switches
between two blur effects made with textures: a soft glow and a radial
zoom.

The intro opens a 640x480 OpenGL window and runs until it is stopped.
It has no sound.

# OPTIONS
This program has no options.

# KEYS
**any key**
:   quit the intro (closing the window also quits).
