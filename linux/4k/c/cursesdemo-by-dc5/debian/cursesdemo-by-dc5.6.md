# NAME
cursesdemo-by-dc5 - run Curses Demo, a text-mode demo released by DC5

# SYNOPSIS
cursesdemo-by-dc5 [**\-\-no-music**]

# DESCRIPTION
Curses Demo is a one-minute demo written in C with ncurses by tfinn of
The Dennis Courtney 5 (DC5). It was released in August 2003 and ranked
3rd in the combined demo compo of Pilgrimage 2003.

Bouncing "DC5" letters, sine scrollers, a little man made of ASCII
characters who plays yo-yo and an expanding star field. The demo uses
the whole terminal, whatever its size, and prints a short message when
it ends.

The soundtrack, Patchbay by Octothorp, is played with **mpg123**(1) from
*/usr/share/cursesdemo-by-dc5/patchbay.mp3*. If mpg123 is not installed,
the demo runs silently.

# OPTIONS
**\-\-no-music**
:   do not play the soundtrack.

# KEYS
**Ctrl+C**
:   stop the demo.

# FILES
*/usr/share/cursesdemo-by-dc5/patchbay.mp3*
:   the soundtrack.
