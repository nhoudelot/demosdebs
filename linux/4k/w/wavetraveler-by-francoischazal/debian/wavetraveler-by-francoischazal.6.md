# NAME
wavetraveler-by-francoischazal - run the Wave Traveler 4k intro

# SYNOPSIS
wavetraveler-by-francoischazal

# DESCRIPTION
Wave Traveler is a 4k intro released by Francois Chazal in 2004. After a
small loading screen, it shows wavelength interferences computed in real
time, in a 400x300 window.

# OPTIONS
This program has no options.

# KEYS
Press any key, or close the window, to quit.

# ENVIRONMENT
**SDL12COMPAT_SYNC_TO_VBLANK**
:   The animation advances by one step per frame, so it is synchronised to
    the vertical blank by default. Set this variable to 0 to disable it.
