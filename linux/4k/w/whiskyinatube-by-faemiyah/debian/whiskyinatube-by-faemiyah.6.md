# NAME
whiskyinatube-by-faemiyah - the command to run Whisky in a Tube.

# SYNOPSIS
whiskyinatube-by-faemiyah [*options*]

# DESCRIPTION
Whisky in a Tube is a 4k intro released by Faemiyah in august 2014.
Ended 7th at Assembly 2014 combined 4k intro compo.

By default the intro starts in fullscreen at the desktop resolution, with
V-Sync enabled. The picture keeps its aspect ratio (black bars are added when
needed), and the window can be resized.

- Juippi: additional code, music
- Trilkk: code

# OPTIONS
\-d [ \-\-developer ]
:    Developer mode.
 
\-R [ \-\-record ]
:    Do not play intro normally, instead save audio as .raw and frames as .png -files
     in the current directory. Use it together with -w.

\-r [ \-\-resolution ] arg
:    Resolution to use, specify as 'WIDTHxHEIGHT', '720p' or '1080p'
     (default: 1280x720). In fullscreen, the picture is scaled to the desktop
     resolution.

\-w [ \-\-window ]
:    Start in window instead of full-screen.
      
\-h [ \-\-help ] 
:    Print help text.

# KEYS
ESC
:	to quit

F
:	toggle fullscreen (desktop resolution)
