# NAME
mindyourhead-by-macslow - run the Mind your head 4k intro by MacSlow

# SYNOPSIS
mindyourhead-by-macslow [*--help*]

# DESCRIPTION
Mind your head is a 4k intro for Linux 64-bit by MacSlow, using SDL 2 and
OpenGL 4. It was released at Revision 2019 (PC 4k intro compo, 13th place).

The intro runs fullscreen at 1920x1080 and has no sound. It quits by itself
after about 90 seconds. A dedicated GPU is recommended.

# OPTIONS

\--help
:   Display help for the command

# KEYS

Escape
:   Quit the intro

# ENVIRONMENT

\_\_GL_SYNC_TO_VBLANK
:   Set to 1 by default by the launcher to enable V-Sync with the NVIDIA
    proprietary driver, as the intro does not request it itself.
