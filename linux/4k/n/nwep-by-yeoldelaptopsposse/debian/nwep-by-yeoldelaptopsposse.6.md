# NAME
nwep-by-yeoldelaptopsposse - the command to run nwep.

# SYNOPSIS
nwep-by-yeoldelaptopsposse

# DESCRIPTION
nwep is a 4k intro released by Ye Olde Laptops Posse & s.k.o.y.p in April 2017.
It ranked 9th in the PC 4k compo at Revision 2017.

w23 (provod) [code, shaders, sync]
keen [music, additional code]
r5ha [additional code]

The intro is rendered at 1280x720 and scaled to the window size, keeping
its aspect ratio.

# OPTIONS
This program has no options.

# KEYS
**F**
: toggle fullscreen (desktop resolution)

**Esc**
: quit
