# NAME
nikak-by-yeoldelaptopsposseskoyp - the command to run nikak.

# SYNOPSIS
nikak-by-yeoldelaptopsposseskoyp

# DESCRIPTION
nikak is a 4k intro released by Ye Olde Laptops Posse & s.k.o.y.p in August 2017.
It ranked 5th in the PC 4k compo at Evoke 2017.

provod [code]
keen [music]

The intro is rendered at 1280x720 and scaled to the window size, keeping
its aspect ratio.

# OPTIONS
This program has no options.

# KEYS
**F**
: toggle fullscreen (desktop resolution)

**Esc**
: quit
