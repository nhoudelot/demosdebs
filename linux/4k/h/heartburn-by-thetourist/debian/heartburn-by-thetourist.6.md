# NAME
heartburn-by-thetourist - the command to run Heartburn.

# SYNOPSIS
heartburn-by-thetourist

# DESCRIPTION
Heartburn is a 4k intro released by The Tourist in august 2013.
Ended 2nd at Buenzli 2013 (combined 64k/4k compo).

TheT(ourist) [Code]

The intro needs OpenGL 4.0. It starts in a 1680x1050 window and stops by
itself after about 75 seconds.

# OPTIONS
This program has no options.

# KEYS
F
:   switch between window and fullscreen (desktop resolution).

Escape, Q
:   quit the intro. Closing the window also quits.

# NOTES
The original Linux binaries were built for a single resolution each. The
Debian version is compiled from the sources: the window can be resized and
the picture keeps the real aspect ratio of the window. V-Sync is enabled.

The frame rate is printed on the standard output while the intro runs.
