# NAME
pinp-by-faemiyah - run piNp, a 4k intro by Faemiyah

# SYNOPSIS
pinp-by-faemiyah

# DESCRIPTION
piNp is a 4k intro by Faemiyah, released in August 2004 at Assembly 2004,
where it ranked 10th in the 4k intro competition.

| Trilkk [Code]
| Juippi [Music]
| Warma [Additional code]

The soundtrack is synthesized at startup, so the screen stays black for
a short while before the intro begins. The Debian version runs in a
window with V-Sync enabled. Press any key to quit.

# OPTIONS
This program has no options.

# ENVIRONMENT
SDL_VIDEODRIVER
:   Video driver used by SDL. The Debian version defaults to x11; set this
    variable to use another driver.
