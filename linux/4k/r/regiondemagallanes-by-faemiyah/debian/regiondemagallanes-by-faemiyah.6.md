# NAME
**regiondemagallanes-by-faemiyah** - the command to run Región de Magallanes.

# SYNOPSIS
**regiondemagallanes-by-faemiyah** [*options*]

# DESCRIPTION
**Región de Magallanes** is a 4k intro released by Faemiyah (Juippi,
Trilkk, Warma) in august 2019. Ended 4th in the PC 4k intro competition
at Assembly 2019.

# OPTIONS
\-d [ \-\-developer ]
:    Developer mode.

\-R [ \-\-record ]
:    Do not play intro normally, instead save audio as .wav and frames as .png -files.

\-r [ \-\-resolution ] arg
:    Resolution to use, specify as 'WIDTHxHEIGHT' or 'HEIGHTp'.

\-w [ \-\-window ]
:    Start in window instead of full-screen.

\-h [ \-\-help ]
:    Print help text.

# KEYS
**F**
:    Toggle fullscreen.

**Esc**
:    Quit.

# FILES
*/usr/share/regiondemagallanes-by-faemiyah/*
:    Shaders and precalculated soundtrack (FLAC).
