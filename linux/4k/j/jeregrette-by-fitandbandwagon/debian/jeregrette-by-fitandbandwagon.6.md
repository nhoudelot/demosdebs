# NAME
jeregrette-by-fitandbandwagon - Je Regrette, 4k intro by Fit and Bandwagon

# SYNOPSIS
**jeregrette-by-fitandbandwagon** [**-w**]

# DESCRIPTION
Je Regrette is a 4k intro for Linux by Fit and Bandwagon, released at
Assembly 2004 (August 2004), where it ranked 5th in the combined 4k intro
competition.

The intro starts in fullscreen with a 640x480 resolution. The music is
generated in real time by a small software synthesizer.

# OPTIONS
**-w**
:   Start in a window instead of fullscreen.

# KEYS
**F**
:   Toggle fullscreen.

**Escape**, **Q**
:   Quit.
