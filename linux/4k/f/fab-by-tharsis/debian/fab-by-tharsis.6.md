# NAME
fab-by-tharsis - 4k intro by Tharsis of Bliss

# SYNOPSIS
fab-by-tharsis

# DESCRIPTION
Fab is a 4k intro written in C with SDL and OpenGL by Tharsis of Bliss,
released in 2004 for the #demoscene 4k source compo, where it ranked 2nd
in the pc 4k competition.

It draws rotating ellipses, a spiral of quads, growing red strips and
clouds of black cubes on a yellow background, in a 640x480 window, with
a Hammond organ tune synthesized in real time. The scenes loop until the
intro is stopped.

The animation runs at 60 frames per second, with vertical synchronization.

# OPTIONS
This program has no options.

# KEYS
**Any key**
:   Quits the intro. Closing the window also quits it.
